Прибыль (страница 2)

Цепочка расчёта

Продажи (Реализовано) − Реклама − Прочее Ozon − Закупка = Прибыль до кредитов и НДС
− Кредиты = «как у Кати» (её строка «Условная прибыль до налогообложения после выплаты кредитов»)
− НДС = Чистая прибыль
Налог на прибыль не считается (решение Андрея, 19.08.2026).

Заказано vs Реализовано

Заказано — оформлено покупателем, может быть отменено (источник: orders_amount, cash-flow).
Реализовано — Ozon подтвердил продажу, используется в расчёте прибыли. Для дневной таблицы источник — sale_amount из начислений Ozon (accrual). Для недель, закрытых до 04.09.2026, «Реализовано» исторически считалось из orders_amount (тот же источник, что и «Заказано») — между двумя источниками есть системное расхождение ~3%, которое сейчас на уточнении у Андрея (см. Журнал изменений). Недели, закрытые после этой даты, будут считаться единообразно — как только вопрос решится.

Диагностика — сверка с файлом Кати

Разовый ручной аудит, проведённый 2026-09-02 по неделям 20.07–30.08.2026: постатейная расшифровка начислений Ozon (/v1/finance/accrual/by-day), сверка каждой строки с файлом Кати. Результат: комиссия и эквайринг совпадают на 0,00 ₽ на всех 6 неделях; логистика — почти точно (расхождение 17–320 ₽, <0,1%); единственное превышение порога сверки (0,1%) — неделя 17–23.08 (0,33%, 828,89 ₽), объяснено округлением одной статьи (type_id_54, «оплата за заказ»). Таблица не растёт дальше 30.08 — у нас нет автоматического доступа к файлу Кати для продолжения сверки.

Ценообразование (страницы 1, 4, 5)

PCT = комиссия(sales_percent_fbo, живая) + эквайринг 1% + возвраты 4,13% + прочие услуги 3,95%.
FIX = себестоимость + логистика(факт из accrual/by-day или резервная тарифная таблица) + последняя миля + хранение(3% от себестоимости) + кросс-докинг(3,21% от закупки).
Безубыточная цена (целевой ДРР 5%) = FIX / (1 − PCT − 0,05) — на целевом ДРР, не на фактическом.
Действие: qty=0 → «Нет продаж 28 дней»; цена < безубыточной → «Поднять цену»; маржа сейчас < 0 ≤ маржа при целевом ДРР → «Починить рекламу»; иначе «ОК».

Как обновляется дашборд

Утро: PowerShell на компьютере Андрея собирает сырые данные из Ozon API, пушит в приватный репозиторий ozon-data. День: облачная рутина «Дашборд Ozon» (GitHub-webhook на пуш в ozon-data) считает все формулы скриптами (scripts/lib_pricing.py, lib_profit.py, build_all.py) и публикует готовые числа в data/*.json публичного репозитория сайта. Никаких чисел вручную в HTML не вписывается — вся логика в скриптах.
