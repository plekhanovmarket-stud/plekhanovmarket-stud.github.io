Как считаю. «Прибыль видимая» = продажи − комиссия Ozon − закупка (закуп+Ермек+упаковка, без колонки L «Себестоимость») − реклама «клик» (сведено по дням из _daily/sku_*.json). В этом прогоне сюда НЕ вошла реклама «оплата за заказ» (CPO, ALL_SKU_PROMO) — асинхронный отчёт был запущен и завершился успешно (см. sku_promo_orders_probe.json), но файл результата (allsku_orders.csv) не попал в выгрузку data/, поэтому по SKU эти суммы недоступны. Значит «видимая прибыль» и «ДРР» ниже — это прибыль/ДРР «клик-онли», выше и ниже соответственно реальных значений. Данные окна 31.07–30.08.2026 (31 день) — упирается в жёсткий лимит Ozon 32 дня для метода реализации; 30.07 не отдался (0 строк), поэтому фактическое окно — 31 день, не 32.

Оценка* без кредита и Оценка* с кредитом в этом прогоне показаны как «—». Раньше эти колонки строились на пропорциональном (по доле продаж SKU) распределении логистики/ хранения/эквайринга/штрафов/возвратов по данным /v1/finance/cash-flow-statement/list и на фиксированной недельной кредитной нагрузке. В свежей выгрузке кредитная нагрузка не имеет источника (см. «Ограничения»), а разбивку логистики/хранения по счёту не удалось надёжно сверить с прежней методикой на новых данных — показывать оценочные суммы без проверки значит рисковать неверными цифрами, поэтому колонки оставлены пустыми до восстановления источника.

Источники. Продажи/комиссия/закупка — sku_realization_32d.json, из POST /v1/finance/realization/by-day по каждому дню окна 31.07–30.08.2026 (31 день) (Seller API). Реклама «клик» — сведена по дням из _daily/sku_2026-{07-31…08-30}.json (кампании «оплата за клик», advObjectType=SKU) — полное дневное покрытие всего окна. Реклама «заказ» (CPO, ALL_SKU_PROMO) — в этом прогоне недоступна: асинхронный отчёт GET /api/client/statistics/all_sku_promo/orders/generate завершился успешно (sku_promo_orders_probe.json), но файл результата (allsku_orders.csv) не сохранён в текущей выгрузке data/. Логистика/склад/кредиты/НДС для оценочной колонки — не сведены на свежих данных (см. «Оценка*» выше), колонка не заполняется.
Ограничения. (1) «Видимая прибыль» и «ДРР» в этой странице — «клик-онли»: без CPO-рекламы прибыль по SKU завышена, а доля SKU в минусе занижена относительно полной методики. (2) Логистика и хранение недоступны по SKU через API Ozon — только по счёту в целом; в этом прогоне оценочная колонка не восстановлена, показана как «—». (3) Окно 31 день — короткое; часть SKU в нём имеют 1–3 дня с продажами (отмечено в комментарии) — для них вывод предварительный, не делайте необратимых решений по одной этой странице. (4) Кредиты («Оценка* с кредитом») — без источника в этом прогоне, оставлены пустыми, не нулевыми.
